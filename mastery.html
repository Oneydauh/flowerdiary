专业显化者指南

鲜花日记操作手册

已熟悉显化方法，可以按功能查找入口、参数和保存规则。加号提供十一项工具；affirm 位于目标详情菜单。

1. 术语与软件名称对照

先核对名称，再查对应操作。通用概念与软件按钮并不总是同名。

通用概念软件名称对应关系
自我概念 · Self-concept新身份“新身份”是当前章节的自我描述字段，只记录自我概念的一部分。
愿景板 · Vision Board愿景板、目标每个目标可保存文字和最多十张图片；分类文件夹与卡片堆是软件的展示方式。
肯定语 · Affirmation目标内 affirm、369书写、自制subaffirm 是读句子、点确认的交互；369 是书写安排；自制sub 可把句子做成音频。三者不是同义词。
脚本书写 · Scripting脚本书写App 按清晨、上午、下午、夜晚组织输入；这四段是软件的写作提示，可只写一段。
369 书写 · 369 Method369书写顶部填今日肯定句，下方设晨三行、中六行、晚九行。“完成此时段”可补齐空白行；三段完成后仍须保存。
感恩记录 · Gratitude Journaling写感谢语写下一件感谢的事再保存，可附图片；它是感恩记录的输入入口。
显化迹象 · Manifestation Signs迹象出现记录相关经历；关联目标时可增加该目标的迹象计数，不会自动把目标标为已显化。
限制性信念 · Limiting Belief限制性信念先保存具体想法；当天记录可点“去释放”。保存信念不会自动完成释放。
释放／Sedona 释放法 · Letting Go / Sedona Method释放练习卡片参考 Sedona 提问框架，实际顺序为“允许→愿意→能否→何时”；也支持使用自己的音频引导。
SUB／阈下音频 · Subliminal Audio自制sub、聆听subApp 制作的是可调人声与背景声的肯定语音频，不会测量个人知觉阈限；制作与聆听是两个入口。
正念冥想 · Mindfulness Meditation冥想面向成年人，提供3、5、12、19、25、45分钟原创中文引导；12/19分钟可选身体主题。首次开始前阅读须知，初次推荐3或5分钟；随时可暂停或结束，不要求忍受不适。

分清概念、工具和记录分类

“章节”是软件对阶段资料的分组，“答案之书”是随机回应工具的名称。肯定语是一类句子；affirm 是目标详情菜单中读句子、点确认的交互；369 是使用肯定语分时段重复书写的工具。369 正式保存后，内容归入“肯定语”日记分类。

2. 目标与 affirm

愿景板管理当前章节的身份、目标与状态。

概念与软件名称

  • 自我概念→新身份 概念与出处
  • 愿景板→愿景板、目标 概念与出处
  • 肯定语→目标内 affirm、369书写、自制sub 概念与出处

操作入口

愿景板 → 添加目标；目标详情 → … → affirm

添加目标时选择分类、填写描述，可加最多十张图片。同类可建多个目标；顶部图标切换文件夹与卡片堆。当前章节摘要展开后可修改新身份。

操作规则
编辑、删除、标记已显化详情菜单或类别内长按菜单；已显化目标不再提供编辑入口。
排序卡片堆长按进入排序，拖动右侧抓手。
affirm文字显示完整后点三次 yes!，随后自动换句；右上角语料库可增删改。
affirm 保存各目标共用同一语料库；确认不会生成日记或自动完成目标。

3. 脚本与 369：草稿、正式保存

两者均按章节与日期保存草稿，正式记录需要另点保存。

概念与软件名称

  • 脚本书写→脚本书写 概念与出处
  • 369 书写→369书写 概念与出处

操作入口

加号 → 脚本书写 / 369书写

工具操作与保存
脚本书写清晨、上午、下午、夜晚分段；可只写一段。点“保存今日脚本”生成日记及练习记录；同一天再次保存更新已有脚本。
369书写顶部填写“今日肯定句”；下方有晨3行、中6行、晚9行独立输入框。每段点“完成此时段”，空白行会用顶部句子补齐，不要求逐行手抄；该段随后只读。三段完成后点“保存今日记录”。
369 正式记录每章节每天一份完整练习，同时生成一篇归入“肯定语”分类的日记；看到“已保存”后即可退出。这只是日记分类名，369与肯定语并非同义词；正式日记保留顶部句子及各行内容。

退出或切到后台会保存草稿；跨日后加载新一天。草稿不计日记篇数，软件不按真实时钟限制三个书写时段。

4. 释放：卡片与音频引导

从当天信念发起，或单独建立释放记录。

概念与软件名称

  • 限制性信念→限制性信念 概念与出处
  • 释放／Sedona 释放法→释放练习 概念与出处

操作入口

加号 → 限制性信念 → 保存 → 去释放；或加号 → 释放练习

模式完成方式
卡片引导填写内容及可选关联目标，开始释放，依次回答卡片；结束时可再来一轮，或点“完成释放”→“好的，完成”。
音频引导导入自己的音频或视频，视频可保留画面或仅取声音；播放后点“完成释放”，补充内容，再点“保存并完成”。

由信念发起会保留原日记、标记已释放，并新增释放练习；独立释放只新增练习记录。取消完成确认不会保存本次练习。历史信念只读，不能回写释放状态。

5. 答案之书

订阅功能；从内置六百六十六页中随机抽取。

操作入口

加号 → 答案之书 → 写问题 → 交给答案之书

提问前可选纸色、纹样与字体。展开后点“收藏”，保存问题、答案、页码及样式；“阅后即焚”不保存本次问答。“再写一封”开启新问题。收藏后可回看，不可编辑；焚毁不会删除以前收藏的信。

6. 自制 SUB：制作与参数

本机录音、系统文字转语音与背景混音。

概念与软件名称

  • SUB／阈下音频→自制sub、聆听sub 概念与出处

操作入口

加号 → 自制sub

  1. 选择录音或文字转语音。录音需要麦克风权限；文字可自己输入，也可选短句或完整文稿。
  2. 录音结束后试听；文字需点“生成语音”，修改文字后重新生成。
  3. 选择内置背景音，或从文件、相册选素材。视频可只取声音，也可保留画面。
  4. 填写不重名的作品名，选择专辑，再设置下表中的参数。
  5. 点“试听当前参数，20 秒”。确认后点“生成专属音频”，成功即保存到音频库。
参数范围 / 默认值
总时长30–600秒 / 180秒，每次增减30秒；须大于肯定语音频时长。
循环间隔1–10秒 / 3秒。
音轨数量1–30轨 / 10轨。
人声峰值−60至−10 dBFS / −28 dBFS；控制成品里人声的强弱；数值越接近0，设置的人声越强，手机播放音量需另调。
文字自动语速有效字数≤100为2倍，101–300为4倍，超过300为6倍；不计标点、空格、表情。

语音语言跟随软件，无独立音色或倍率选项。修改参数后重新试听；未生成即退出的录音、素材会清理。正式作品存入音频库，当前没有单条音频导出或分享入口。

7. 音频库、小鹿与定时

专辑用于归类自制作品，不是外部音频导入器。

概念与软件名称

  • SUB／阈下音频→自制sub、聆听sub 概念与出处

操作入口

加号 → 聆听sub

进入后页面标题为“我的音频库”，选择专辑和作品即可播放。

搜索匹配专辑名、作品名和文字转语音原文。专辑菜单可新建、编辑、查看全部音频或制作 SUB；作品菜单可移至专辑、重命名、删除。自建专辑可选封面照片，删除后作品转入“未归类”；内置专辑不可删。

播放器可拖进度、播放/暂停、停止及下一首；循环键切换单曲循环、专辑顺序循环、随机播放。定时键可选15、30、60分钟或关闭定时。

正式播放会显示小鹿：轻点展开，点曲名回完整播放器，拖动可贴靠左右边。暂停时小鹿睡觉，停止后消失。离开页面仍可后台播放；制作试听不显示小鹿。专辑分钟数是作品总长，不是累计聆听时长。

8. 冥想：播放与完成记录

面向成年人的身体与呼吸觉察练习，初次推荐3或5分钟；可以随时结束，不要求忍受不适。

概念与软件名称

  • 正念冥想→冥想 概念与出处

操作入口

加号 → 冥想 → 选择时长 → 开始冥想

  1. 选择3、5、12、19、25或45分钟。首次及重要须知更新后，先阅读“练习前须知”，自主选择开始或暂不开始。
  2. 开头12秒包含准备和轻钵提示，随后跟随中文引导进行身体与自然呼吸觉察；安静时段继续按刚才的方法练习。英文界面也使用中文配音。
  3. 暂停和“结束本次练习”固定在页面下方；可以睁眼、调整坐姿，出现不适时停止。反馈入口会先暂停音频，不会自动恢复。
  4. 结束后可查看感受与注意事项，或从冥想页、个人中心主动反馈。反馈不自动附加日记或设备标识，邮件发送前由你确认。
  5. 完整结束且保存成功会留下使用记录，不代表健康效果；中途结束不要求补做，不影响其他功能。

六种时长包含开头12秒准备和温和收尾。使用随应用提供的原创中文合成配音，可离线播放；3/5分钟首尾有轻钵，12分钟以上另有中段提示。12/19分钟可以选择身体主题，脉轮名称只说明传统背景。

什么时候计入统计

每次完整结束并保存成功计一篇，进入日记、花园冥想分类、首页记录统计及个人中心跨章节使用统计；提前结束不记。记录归入开始练习时的章节，不因练习期间切换章节而改写归属；重复重试保存不会多记一篇。

9. 日记：搜索、分类与只读规则

底部日记的三个视图均对应当前活动章节。

概念与软件名称

  • 感恩记录→写感谢语 概念与出处
  • 显化迹象→迹象出现 概念与出处
  • 限制性信念→限制性信念 概念与出处
入口范围与操作
今日搜索当天关键词、类型或心情；照片可点开查看。
月历切换月份、选择日期，回看当日日记与释放。
花园纵向浏览，点类别标签；latest · 是该类最新日期，释放按完成时间。

感谢语、迹象、限制性信念需正文；心情感受可只选标签。四类均可加最多九张图片。关联维度最终仅匹配一个目标；关联迹象会增加该目标迹象数。

仅当前未归档章节的当天记录可编辑或删除；收藏问答不可编辑。过去日期与历史章节只读，无补记或改日期入口。进入工具后返回可重选，工具面板空白处关闭。

10. 分享与使用统计

分享生成图片；统计汇总正式日记。

入口输出或统计范围
日记 → 今日 → 分享完整当天长图，含释放；当前搜索不会截取分享内容。
日记 → 月历 → 日期 → 分享当日日记分享卡，可选可用样式。
历史章节 → 章节详情 → 分享章节摘要与日记分页图片，可左右预览。
个人中心 → 使用统计跨章节累计日记、记录天数、最长连续；切年份、点方块看某日篇数。

脚本、369正式保存生成的日记，以及完整结束并保存成功的冥想，均计入篇数；草稿、affirm点击、音频播放及独立释放不计。2026年网格显示下半年。分享图片不能恢复应用数据。

11. 章节、同步与设置

归档保留一段阶段记录，删除则移除数据。

操作入口

愿景板 → 归档当前章节；个人中心 → 历史章节

归档后填写新身份开启下一章；历史章可回看与分享，不能恢复为活动章。历史列表左滑删除会清空该章记录，无法撤销。

个人中心选项用途
iCloud 同步查看账户、同步状态与诊断；同一 Apple 账户的私人 CloudKit 同步由系统调度，检查账户不等于强制上传。
优化现有数据整理资源与数据库占用，执行前自动校验私有恢复备份；不是用户导出入口。
外观与字体 / 语言调主题、字体、字号与语言；深色适配系统外观。
面容解锁需支持并设置 Face ID；进入后台后重新锁定。
订阅免费版三个目标、一个音频、一个归档；其他权限与价格看应用内，购买页可恢复购买。

换设备前确认图片、音频已同步；发生差异先保留两端数据，再查诊断。当前没有全量 ZIP、JSON 或 PDF 导出入口。
