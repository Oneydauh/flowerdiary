專業顯化者指南

鮮花日記操作手冊

已熟悉顯化方法，可以按功能查找入口、參數和保存規則。加號提供十一項工具；affirm 位於目標詳情菜單。

1. 術語與軟體名稱對照

先核對名稱，再查對應操作。通用概念與軟體按鈕並不總是同名。

通用概念軟體名稱對應關係
自我概念 · Self-concept新身份“新身份”是當前章節的自我描述字段，只記錄自我概念的一部分。
願景板 · Vision Board願景板、目標每個目標可保存文字和最多十張圖片；分類資料夾與卡片堆是軟體的展示方式。
肯定語 · Affirmation目標內 affirm、369書寫、自制subaffirm 是讀句子、點確認的交互；369 是書寫安排；自制sub 可把句子做成音訊。三者不是同義詞。
腳本書寫 · Scripting腳本書寫App 按清晨、上午、下午、夜晚組織輸入；這四段是軟體的寫作提示，可只寫一段。
369 書寫 · 369 Method369書寫頂部填今日肯定句，下方設晨三行、中六行、晚九行。“完成此時段”可補齊空白行；三段完成後仍須保存。
感恩記錄 · Gratitude Journaling寫感謝語寫下一件感謝的事再保存，可附圖片；它是感恩記錄的輸入入口。
顯化跡象 · Manifestation Signs跡象出現記錄相關經歷；關聯目標時可增加該目標的跡象計數，不會自動把目標標為已顯化。
限制性信念 · Limiting Belief限制性信念先保存具體想法；當天記錄可點“去釋放”。保存信念不會自動完成釋放。
釋放／Sedona 釋放法 · Letting Go / Sedona Method釋放練習卡片參考 Sedona 提問框架，實際順序為“允許→願意→能否→何時”；也支持使用自己的音訊引導。
SUB／閾下音訊 · Subliminal Audio自制sub、聆聽subApp 製作的是可調人聲與背景聲的肯定語音訊，不會測量個人知覺閾限；製作與聆聽是兩個入口。
正念冥想 · Mindfulness Meditation冥想面向成年人，提供3、5、12、19、25、45分鐘原創中文引導；12/19分鐘可選身體主題。首次開始前閱讀須知，初次推薦3或5分鐘；隨時可暫停或結束，不要求忍受不適。

分清概念、工具和記錄分類

“章節”是軟體對階段資料的分組，“答案之書”是隨機回應工具的名稱。肯定語是一類句子；affirm 是目標詳情菜單中讀句子、點確認的交互；369 是使用肯定語分時段重復書寫的工具。369 正式保存後，內容歸入“肯定語”日記分類。

2. 目標與 affirm

願景板管理當前章節的身份、目標與狀態。

概念與軟體名稱

  • 自我概念→新身份 概念與出處
  • 願景板→願景板、目標 概念與出處
  • 肯定語→目標內 affirm、369書寫、自制sub 概念與出處

操作入口

願景板 → 添加目標；目標詳情 → … → affirm

添加目標時選擇分類、填寫描述，可加最多十張圖片。同類可建多個目標；頂部圖標切換資料夾與卡片堆。當前章節摘要展開後可修改新身份。

操作規則
編輯、刪除、標記已顯化詳情菜單或類別內長按菜單；已顯化目標不再提供編輯入口。
排序卡片堆長按進入排序，拖動右側抓手。
affirm文字顯示完整後點三次 yes!，隨後自動換句；右上角語料庫可增刪改。
affirm 保存各目標共用同一語料庫；確認不會生成日記或自動完成目標。

3. 腳本與 369：草稿、正式保存

兩者均按章節與日期保存草稿，正式記錄需要另點保存。

概念與軟體名稱

  • 腳本書寫→腳本書寫 概念與出處
  • 369 書寫→369書寫 概念與出處

操作入口

加號 → 腳本書寫 / 369書寫

工具操作與保存
腳本書寫清晨、上午、下午、夜晚分段；可只寫一段。點“保存今日腳本”生成日記及練習記錄；同一天再次保存更新已有腳本。
369書寫頂部填寫“今日肯定句”；下方有晨3行、中6行、晚9行獨立輸入框。每段點“完成此時段”，空白行會用頂部句子補齊，不要求逐行手抄；該段隨後只讀。三段完成後點“保存今日記錄”。
369 正式記錄每章節每天一份完整練習，同時生成一篇歸入“肯定語”分類的日記；看到“已保存”後即可退出。這只是日記分類名，369與肯定語並非同義詞；正式日記保留頂部句子及各行內容。

退出或切到後台會保存草稿；跨日後加載新一天。草稿不計日記篇數，軟體不按真實時鐘限制三個書寫時段。

4. 釋放：卡片與音訊引導

從當天信念發起，或單獨建立釋放記錄。

概念與軟體名稱

  • 限制性信念→限制性信念 概念與出處
  • 釋放／Sedona 釋放法→釋放練習 概念與出處

操作入口

加號 → 限制性信念 → 保存 → 去釋放；或加號 → 釋放練習

模式完成方式
卡片引導填寫內容及可選關聯目標，開始釋放，依次回答卡片；結束時可再來一輪，或點“完成釋放”→“好的，完成”。
音訊引導導入自己的音訊或影片，影片可保留畫面或僅取聲音；播放後點“完成釋放”，補充內容，再點“保存並完成”。

由信念發起會保留原日記、標記已釋放，並新增釋放練習；獨立釋放只新增練習記錄。取消完成確認不會保存本次練習。歷史信念只讀，不能回寫釋放狀態。

5. 答案之書

訂閱功能；從內置六百六十六頁中隨機抽取。

操作入口

加號 → 答案之書 → 寫問題 → 交給答案之書

提問前可選紙色、紋樣與字體。展開後點“收藏”，保存問題、答案、頁碼及樣式；“閱後即焚”不保存本次問答。“再寫一封”開啓新問題。收藏後可回看，不可編輯；焚毀不會刪除以前收藏的信。

6. 自制 SUB：製作與參數

本機錄音、系統文字轉語音與背景混音。

概念與軟體名稱

  • SUB／閾下音訊→自制sub、聆聽sub 概念與出處

操作入口

加號 → 自制sub

  1. 選擇錄音或文字轉語音。錄音需要麥克風權限；文字可自己輸入，也可選短句或完整文稿。
  2. 錄音結束後試聽；文字需點“生成語音”，修改文字後重新生成。
  3. 選擇內置背景音，或從文件、相冊選素材。影片可只取聲音，也可保留畫面。
  4. 填寫不重名的作品名，選擇專輯，再設定下表中的參數。
  5. 點“試聽當前參數，20 秒”。確認後點“生成專屬音訊”，成功即保存到音訊庫。
參數範圍 / 默認值
總時長30–600秒 / 180秒，每次增減30秒；須大於肯定語音訊時長。
循環間隔1–10秒 / 3秒。
音軌數量1–30軌 / 10軌。
人聲峰值−60至−10 dBFS / −28 dBFS；控製成品里人聲的強弱；數值越接近0，設定的人聲越強，手機播放音量需另調。
文字自動語速有效字數≤100為2倍，101–300為4倍，超過300為6倍；不計標點、空格、表情。

語音語言跟隨軟體，無獨立音色或倍率選項。修改參數後重新試聽；未生成即退出的錄音、素材會清理。正式作品存入音訊庫，當前沒有單條音訊導出或分享入口。

7. 音訊庫、小鹿與定時

專輯用于歸類自製作品，不是外部音訊導入器。

概念與軟體名稱

  • SUB／閾下音訊→自制sub、聆聽sub 概念與出處

操作入口

加號 → 聆聽sub

進入後頁面標題為“我的音訊庫”，選擇專輯和作品即可播放。

搜索匹配專輯名、作品名和文字轉語音原文，左側可選擇專輯或全部。菜單可管理專輯、移動作品、重命名和刪除。默認與自建專輯均可刪除，作品轉入未歸類；空專輯會保留，新建專輯必須填寫名稱。

播放器可拖進度、播放/暫停、停止及下一首；循環鍵切換單曲循環、專輯順序循環、隨機播放。定時鍵可選15、30、60分鐘或關閉定時。

正式播放會顯示小鹿：輕點展開，點曲名回完整播放器，拖動可貼靠左右邊。暫停時小鹿睡覺，停止後消失。離開頁面仍可後台播放；製作試聽不顯示小鹿。專輯分鐘數是作品總長，不是累計聆聽時長。

8. 冥想：播放與完成記錄

面向成年人的身體與呼吸覺察練習，初次推薦3或5分鐘；可以隨時結束，不要求忍受不適。

概念與軟體名稱

  • 正念冥想→冥想 概念與出處

操作入口

加號 → 冥想 → 選擇時長 → 開始冥想

  1. 選擇3、5、12、19、25或45分鐘。首次及重要須知更新後，先閱讀“練習前須知”，自主選擇開始或暫不開始。
  2. 開頭12秒包含準備和輕鉢提示，隨後跟隨中文引導進行身體與自然呼吸覺察；安靜時段繼續按剛才的方法練習。英文界面也使用中文配音。
  3. 暫停和“結束本次練習”固定在頁面下方；可以睜眼、調整坐姿，出現不適時停止。反饋入口會先暫停音訊，不會自動恢復。
  4. 結束後可查看感受與注意事項，或從冥想頁、個人中心打開用戶反饋，選擇 App Store 評價或小紅書留言、私信；不會附加日記或設備資訊。
  5. 完整結束且保存成功會留下使用記錄，不代表健康效果；中途結束不要求補做，不影響其他功能。

六種時長包含開頭12秒準備和溫和收尾。使用隨應用提供的原創中文合成配音，可離線播放；3/5分鐘首尾有輕鉢，12分鐘以上另有中段提示。12/19分鐘可以選擇身體主題，脈輪名稱只說明傳統背景。

什麼時候計入統計

每次完整結束並保存成功計一篇，進入日記、花園冥想分類、首頁記錄統計及個人中心跨章節使用統計；提前結束不記。記錄歸入開始練習時的章節，不因練習期間切換章節而改寫歸屬；重復重試保存不會多記一篇。

9. 日記：搜索、分類與只讀規則

底部日記的三個視圖均對應當前活動章節。

概念與軟體名稱

  • 感恩記錄→寫感謝語 概念與出處
  • 顯化跡象→跡象出現 概念與出處
  • 限制性信念→限制性信念 概念與出處
入口範圍與操作
今日搜索當天關鍵詞、類型或心情；照片可點開查看。
月曆切換月份、選擇日期，回看當日日記與釋放。
花園縱向瀏覽，點類別標籤；latest · 是該類最新日期，釋放按完成時間。

感謝語、跡象、限制性信念需正文；心情感受可只選標籤。四類均可加最多九張圖片。關聯維度最終僅匹配一個目標；關聯跡象會增加該目標跡象數。

僅當前未歸檔章節的當天記錄可編輯或刪除；收藏問答不可編輯。過去日期與歷史章節只讀，無補記或改日期入口。進入工具後返回可重選，工具面板空白處關閉。

10. 分享與使用統計

分享生成圖片；統計匯總正式日記。

入口輸出或統計範圍
日記 → 今日 → 分享完整當天長圖，含釋放；當前搜索不會截取分享內容。
日記 → 月曆 → 日期 → 分享當日日記分享卡，可選可用樣式。
歷史章節 → 章節詳情 → 分享章節摘要與日記分頁圖片，可左右預覽。
個人中心 → 使用統計跨章節累計日記、記錄天數、最長連續；切年份、點方塊看某日篇數。

腳本、369正式保存生成的日記，以及完整結束並保存成功的冥想，均計入篇數；草稿、affirm點擊、音訊播放及獨立釋放不計。2026年網格顯示下半年。分享圖片不能恢復應用數據。

11. 章節、同步與設定

歸檔保留一段階段記錄，刪除則移除數據。

操作入口

願景板 → 歸檔當前章節；個人中心 → 歷史章節

歸檔後填寫新身份開啓下一章；歷史章可回看與分享，不能恢復為活動章。歷史列表左滑刪除會清空該章記錄，無法撤銷。

個人中心選項用途
iCloud 同步查看賬戶、同步狀態與診斷；同一 Apple 賬戶的私人 CloudKit 同步由系統調度，檢查賬戶不等於強制上傳。
優化現有數據整理資源與數據庫佔用，執行前自動校驗私有恢復備份；不是用戶導出入口。
外觀與字體 / 語言調主題、字體、字號與語言；深色適配系統外觀。
面容解鎖需支持並設定 Face ID；進入後台後重新鎖定。
訂閱免費版三個目標、一個音訊、一個歸檔；其他權限與價格看應用內，購買頁可恢復購買。

換設備前確認圖片、音訊已同步；發生差異先保留兩端數據，再查診斷。也可在個人中心 → 備份與遷移中導出和導入本地備份。日記分享圖片不能代替數據備份。
